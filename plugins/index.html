הפלאגינים שלי ל-Claude

מה זה פלאגין?

פלאגין הוא תוסף שנותן לו כלים או יכולות נוספות, למשל לעבוד עם שירות מסוים או לבצע משימות בדרך שמותאמת לצרכים שלך. זה קצת כמו לצרף לקלוד ערכת עבודה מוכנה, במקום להסביר לו בכל פעם מחדש איך לעבוד.

הכתובת של החנות

tamardobrin/claude-plugins

את זה מדביקים בשלב 3 למטה.

איך מתקינים

  1. פותחים את Claude

    באתר claude.ai או באפליקציה של Claude למחשב.

  2. נכנסים לפלאגינים

    בתפריט שבצד: Customize ← Plugins

  3. מוסיפים את החנות שלי

    לוחצים Add ← Add marketplace, מדביקים את הכתובת שהעתקתם, ולוחצים Add. עושים את זה רק פעם אחת.

  4. מתקינים פלאגין

    הפלאגינים שלי מופיעים ברשימה. בוחרים אחד ולוחצים Install.

  5. משתמשים

    פותחים שיחה חדשה ופשוט מבקשים. Claude יודע לבד מתי להשתמש בפלאגין. יש דוגמאות לכל פלאגין למטה.

לא רואים Plugins בתפריט? יש תשובה בשאלות למטה.

שאלות

אני לא רואה Plugins בתפריט ⌄

כמה דברים לבדוק: שהאפליקציה מעודכנת לגרסה האחרונה, ושאתם מחוברים לחשבון הנכון. בחשבון של עבודה, מנהל החשבון יכול לחסום הוספה של חנויות, ואז צריך לבקש ממנו.

אם זה עדיין לא עובד ואתם רוצים רק את הפרומפטים ל-Seedance, יש דרך שעובדת בכל חשבון: פרומפט אחד שמעתיקים ל-Claude.

זה עולה כסף? ⌄

הפלאגינים שלי חינמיים. צריך חשבון Claude, ופלאגינים שמסומנים "Claude Code" דורשים מנוי בתשלום (Pro ומעלה). יצירת סרטונים ב-Higgsfield עולה קרדיטים שם.

אני משתמש/ת ב-Claude Code ⌄

מוסיפים את החנות ומתקינים עם הפקודות האלה (מחליפים את השם בשם של הפלאגין):

/plugin marketplace add tamardobrin/claude-plugins
/plugin install eli5@tamardobrin-plugins

או פשוט מקלידים /plugin ובוחרים מהרשימה.

איך מקבלים עדכונים? ⌄

פלאגינים מחנויות פרטיות לא מתעדכנים לבד. כשאני מעדכנת פלאגין, נכנסים לאותו מסך של הפלאגינים ומעדכנים את החנות. ב-Claude Code: /plugin ← Marketplaces, ושם אפשר גם להפעיל עדכון אוטומטי.

זה בטוח? ⌄

פלאגין יכול לתת ל-Claude יכולות חדשות, וחלקם מריצים דברים במחשב. לכן כדאי להתקין רק מאנשים שסומכים עליהם. כל הפלאגינים שלי פתוחים לקריאה ב-GitHub.
